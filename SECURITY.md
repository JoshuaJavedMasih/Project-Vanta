# Security Policy

## Supported version

Security fixes are currently applied to the latest Vanta 1.x release.

## Reporting a vulnerability

Please report suspected vulnerabilities privately to Merhatta Softwares before opening a public issue. Include:

- A clear description of the issue
- Affected Vanta version
- Windows version and architecture
- Reproduction steps or a proof of concept
- Potential impact
- Any suggested mitigation

Do not include passwords, access tokens, private diagnostic exports, personal information, or machine identifiers in reports.

## Security principles

- Standard-user operation by default
- Least-privilege access to Windows APIs
- Read-only Phase 1 telemetry
- No personal analytics collection
- No packet interception
- No fabricated security or health claims
- Privacy-safe exports with identifying fields omitted
