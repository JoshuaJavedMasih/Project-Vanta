# Changelog

All notable Vanta changes are documented here.

## 1.0.0 — 2026-08-27

### Added

- Native C#/.NET 8/WinUI 3 application foundation
- Compact premium monitoring dashboard and generated Vanta brand mark
- CPU, memory, storage, network, process, uptime, and GPU identity collection
- One-second asynchronous monitoring service and rolling chart buffers
- Simulated telemetry provider for deterministic interface development
- Focused intelligence views and privacy-safe JSON report export
- Conservative system-health evaluation
- Six automated MSTest tests
- Merhatta Softwares ownership, executable metadata, and copyright notices
- Self-contained Windows x64 release workflow

### Known limitations

- Temperature, fan, SMART/NVMe, and some GPU signals require optional future providers.
- History retention, signed installer packaging, and privileged system-management actions are not included in Phase 1.
